# gravitas-thinking

A model-neutral working discipline for AI coding agents on game builds,
adapted from [Gravitas](https://github.com/udaysharmadev/Gravitas) (MIT).
Start with [SKILL.md](SKILL.md). The full game plan every build starts from
lives in [templates/game-plan.md](templates/game-plan.md) with a checker
script in [scripts/plan-check.mjs](scripts/plan-check.mjs). Paste-ready
texts per model live in [adapters/](adapters/): Gemini, Claude, ChatGPT,
repo-reading coding agents, and one prompt for any chat model.

These agreements make any model's work verifiable. They do not turn one
model into another model; no prompt can. Licence: MIT (see
[LICENSE](LICENSE), sources in [CREDITS.md](CREDITS.md)).
